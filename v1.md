## Operating System

- Ubuntu 26.04 Server Install (downloaded 04/08/2026)
- Regular install, do NOT automatically detect Nvidia hardware and install drivers. This will install version 595 of the NVIDIA drivers, which are not the most recent ones.

### List devices

### Driver Install

- Follow the [Driver Installation Guide](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/latest/ubuntu.html) from NVIDIA documentation site,
including pre-requisites etc.
- Use driver version pinning. To search for correct versions:

```
$ sudo apt-cache search nvidia-driver-pinning
  # OR
$ ubuntu-drivers devices
```

- Install the pinning package
- Install the driver
- Chose the `open kernel modules` of the `compute-only system` ([link](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/latest/ubuntu.html#compute-only-system))
- reboot, post-install steps
