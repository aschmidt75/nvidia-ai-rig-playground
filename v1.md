### Driver Install

- Follow the [Driver Installation Guide](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/latest/ubuntu.html) from NVIDIA documentation site,
including pre-requisites etc.
- Use driver version pinning. To search for correct versions:

```
$ sudo apt-cache search nvidia-driver-pinning
  # OR
$ ubuntu-drivers devices
```

- Install the pinning package
- Install the driver
- Chose the `open kernel modules` of the `compute-only system` ([link](https://docs.nvidia.com/datacenter/tesla/driver-installation-guide/latest/ubuntu.html#compute-only-system))
- reboot, post-install steps

- Testing model `RedHatAI/Mistral-7B-Instruct-v0.3-GPTQ-4bit` as a 4bit quantized model with tooling

```
vllm serve \
  RedHatAI/Mistral-7B-Instruct-v0.3-GPTQ-4bit \
  --tokenizer_mode hf \
  --config_format hf \
  --load_format hf \
  --enable-auto-tool-choice \
  --tool-call-parser mistral \
  --chat-template vllm/examples/tool_chat_template_mistral_parallel.jinja \
  --max-model-len 16384 \
  --gpu-memory-utilization 0.90 \
  --port 8000
```

Running `NVIDIA-Nemotron-3-Nano-4B-FP8` with flash attention (takes time to pre-compile). Allows for 32kb context.

```sh
VLLM_ATTENTION_BACKEND=FLASH_ATTN vllm \
  serve nvidia/NVIDIA-Nemotron-3-Nano-4B-FP8 \
  --dtype auto \
  --max-model-len 32768 \
  --gpu-memory-utilization 0.85 \
  --port 8000
```

```
vllm bench serve --model nvidia/NVIDIA-Nemotron-3-Nano-4B-FP8   --num-prompts 100   --request-rate 4   --input-len 256   --output-len 128
```
